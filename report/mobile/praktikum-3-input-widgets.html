Input Widgets dan Basic Form

Mata Kuliah Aplikasi Mobile — Flutter

Selesai

1.1 Tujuan

Praktikum ini bertujuan untuk memahami cara membuat form dasar pada Flutter, menerima input dari keyboard, membaca nilai input, serta melakukan validasi data sebelum diproses.

  1. Membuat beberapa input widget seperti TextField dan TextFormField.
  2. Mengontrol input pengguna menggunakan TextEditingController.
  3. Membuat form dengan validasi menggunakan Form dan GlobalKey<FormState>.
  4. Membuat aplikasi kalkulator dengan dua input angka dan operasi kabataku.

1.2 Alat

  • Komputer atau laptop.
  • Flutter SDK dan Dart SDK.
  • Visual Studio Code atau IDE sejenis.
  • Android Emulator dan iPhone Simulator untuk pengujian lintas platform.

1.3 Dasar Teori

Basic Form

Form merupakan komponen antarmuka yang digunakan untuk menerima dan mengelola input pengguna. Dalam Flutter, form dapat berisi berbagai input widget seperti TextField, TextFormField, checkbox, switch, dropdown, radio, dan tombol.

TextField

TextField digunakan untuk menerima input teks secara langsung. Nilainya dapat dibaca menggunakan controller, sedangkan InputDecoration digunakan untuk mengatur label, hint, border, dan icon.

TextFormField dan Validator

TextFormField memiliki kemampuan validasi melalui fungsi validator. Jika data tidak sesuai, validator mengembalikan pesan error. Jika data valid, validator mengembalikan null.

Controller, FormState, dan State

TextEditingController membaca nilai input, GlobalKey<FormState> mengakses status form, dan validate() menjalankan seluruh validator. Karena input dapat berubah, form dibuat menggunakan StatefulWidget dan dibersihkan melalui dispose().

A. Membuat project dan file contoh

Project Flutter digunakan sebagai dasar pengerjaan. Contoh input dibuat dalam file terpisah agar setiap form dapat dijalankan dan diuji secara mandiri.

lib/form-textfield.dart — contoh input tanpa validasi Form. lib/form-textformfield.dart — contoh input dengan validasi Form. lib/calculator.dart — tugas Kelas A.

  1. Buat StatefulWidget untuk menampung form.
  2. Tambahkan TextEditingController pada state.
  3. Pasang controller pada TextField.
  4. Tambahkan tombol ElevatedButton.
  5. Ambil nilai controller dan tampilkan menggunakan SnackBar.
